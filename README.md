# Me

A personal life hub web app. The first module is a zoomable life timeline with events, descriptions and photos. To-do and calendar modules are planned.

- **Frontend:** Next.js + TypeScript + Tailwind (`frontend/`)
- **Backend:** Python + FastAPI (`backend/`)
- **Database, auth, storage:** Supabase

## Local setup

See the "Run locally" section in [CLAUDE.md](CLAUDE.md). Copy each `.env.example` file to `.env` (backend) or `.env.local` (frontend) and fill in your Supabase project keys.
